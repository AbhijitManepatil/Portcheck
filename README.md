# Portcheck

GPU Port Check: an open-source, self-hosted toolkit that checks whether a CUDA-based AI inference workload can move from NVIDIA to AMD ROCm, and proves it with measurements. It will ship as a CLI, an MCP server and Claude skills.

**Status:** specification only. No application code has been written yet.

- [`IMPLEMENTATION_SPEC.md`](IMPLEMENTATION_SPEC.md): the build spec, written for a coding agent. Tasks T1 to T12 are in section 12.
- [`HANDOFF.md`](HANDOFF.md): context, decisions already made, open points, and a kickoff prompt.
